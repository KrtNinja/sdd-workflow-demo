# Site Search — Brainstorming

Исходный запрос продукта: **«Добавьте контекстный поиск по сайту с горячими клавишами»**.

Агент задаёт вопросы по одному и предлагает варианты. Решает человек (разработчик + продакт).
Из этой таблицы собирается Dev Spec. Сам документ — протокол решений, его не правят задним числом.

## Что агент решил бы сам, если отдать задачу одним промптом

| Вопрос | Вероятная догадка агента | Чем плохо |
|---|---|---|
| Что значит «контекстный»? | Подсказки при вводе | Продукт мог иметь в виду поиск внутри раздела |
| Какие клавиши? | Ctrl+K | На macOS нужен Cmd+K, многие ждут «/» |
| Русская раскладка | Сравнение по символу | Ctrl+Л молча не работает |
| «/» во время набора текста | Перехват всегда | Нельзя набрать «/» в отзыве |
| Медленные ответы | Рендерим каждый | Старый ответ перетирает свежий |
| Неправильная раскладка | Не обрабатываем | «yjen» → ничего, хотя искали «ноут» |
| Нет в наличии | Скрыть или наравне | Влияет на конверсию, это решение продукта |
| Чем искать на сервере | Что-то из популярного | Выбор движка без обсуждения |
| Свежесть остатков | Из индекса | Товар продан, а в подсказке «в наличии» |

## Решения: интерфейс

| # | Вопрос | Решение |
|---|---|---|
| Q1 | Что значит «контекстный»? | Подсказки при вводе + учёт текущего раздела. Семантика позже |
| Q2 | Какие клавиши? | Ctrl+K (Win/Linux), Cmd+K (macOS), «/» |
| Q3 | Раскладка | По физической клавише: Ctrl+Л тоже открывает поиск |
| Q4 | «/» в поле ввода | В полях ввода «/» не трогаем. Ctrl/Cmd+K работает везде |
| Q5 | С какой длины подсказки | С 2 символов, пауза ввода 200 мс |
| Q6 | Что показывать | До 8 товаров и до 3 категорий |
| Q7 | Поиск в разделе | Сначала раздел, переключатель «Во всём магазине» |
| Q8 | Неправильная раскладка | Если пусто — пробуем перевод раскладки, показываем «Показаны результаты для „ноут“» |
| Q9 | Опечатки | Вне scope |
| Q10 | Нет в наличии | Показывать ниже доступных, с пометкой |
| Q11 | Enter без выбора | Страница результатов поиска |
| Q12 | Мобильные | Только иконка, без хоткеев |

## Решения: сервер

| # | Вопрос | Решение |
|---|---|---|
| B1 | Чем искать | PostgreSQL (каталог 50 000 товаров). Движок за портом. См. [ADR-0001](../adr/0001-search-engine.md) |
| B2 | Морфология | Словоформы: «ноутбука» находит «ноутбук» |
| B3 | Незаконченное слово | Префикс последнего слова: «ноут» находит «ноутбук» |
| B4 | Порядок выдачи | В наличии → релевантность → продажи за 30 дней |
| B5 | Раздел | Всё поддерево категорий |
| B6 | Свежесть | Наличие — на момент запроса |
| B7 | Снятые с продажи | Не показывать |
| B8 | Нагрузка | Ограничение частоты запросов на клиента |
| B9 | Кто переводит раскладку | Сервер, в одном запросе (иначе вторая гонка ответов) |
| B10 | Поиск недоступен | Понятное сообщение, страница работает |

Самые дорогие решения — Q3, Q4 и B6. Их бы не поймали на ревью кода.
