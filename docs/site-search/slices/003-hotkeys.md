# 003 — Горячие клавиши

Тип: поведение
Основание: FR-1, FR-2, NFR-3
Зависимости: frontend-половина 002 (панель открывается по иконке)
Половины: только frontend
Результат: на десктопе поиск открывается с клавиатуры на любой странице

## Контракты
Не использует API.

## Приёмка
AC-003-1 Открытие
  WHEN фокус на странице, нажато Ctrl+K (Windows) или Cmd+K (macOS)
  THEN панель открыта, фокус в поле ввода

AC-003-2 Русская раскладка
  WHEN раскладка русская, нажато Ctrl+Л
  THEN панель открыта

AC-003-3 Слэш
  WHEN фокус на странице, нажата «/»
  THEN панель открыта, «/» не попал в поле поиска

AC-003-4 Слэш при наборе текста
  WHEN курсор в редакторе отзыва, нажата «/»
  THEN в редакторе появился «/», панель закрыта

AC-003-5 Ctrl+K при наборе текста
  WHEN курсор в редакторе отзыва, нажато Ctrl+K
  THEN панель открыта

AC-003-6 Поиск уже открыт
  WHEN панель открыта, в поле «ноут», нажато Ctrl+K
  THEN фокус в поле, текст «ноут» выделен
  (добавлен после review-slices, FR-1 уточнён)

AC-003-7 Модальный диалог
  WHEN открыта корзина, нажато Ctrl+K
  THEN панель поиска не открывается
  (добавлен после JIT-вопроса при создании Change, FR-1 уточнён)

AC-003-8 Мобильные
  WHEN ширина экрана 375 px, нажато Ctrl+K
  THEN ничего не происходит

## Границы
Вне slice: навигация стрелками и ARIA (004), раздел (005).
Не меняет разметку списка подсказок — только вызывает открытие панели.

## Definition of Done
- Все AC-003-* закрыты тестами с AC-ID в названиях
- Change удалён
