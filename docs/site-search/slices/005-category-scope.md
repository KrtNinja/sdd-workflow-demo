# 005 — Поиск в разделе

Тип: поведение
Основание: FR-4, FR-12
Зависимости: 002, 006 (порядок FR-9 → FR-4)
Половины: backend + frontend, принимаются вместе
Результат: на странице раздела подсказки учитывают раздел и все его подразделы

## Контракты
- `contracts/search.openapi.yaml` — параметр categoryId, поле scope (не меняются)
- порт `CategoryTree`

## Общая приёмка
AC-005-1 Только раздел
  WHEN страница «Ноутбуки», запрос «чехол»
  THEN в подсказках «Чехол для ноутбука 15"», переключатель в положении «В разделе»

AC-005-2 Подразделы
  WHEN страница «Ноутбуки», запрос «игровой»
  THEN в подсказках «Игровой ноутбук G7» из подраздела «Игровые ноутбуки»

AC-005-3 Пусто в разделе
  WHEN страница «Ноутбуки», запрос «мышь»
  THEN заголовок «В разделе ничего не нашлось», ниже «Мышь беспроводная M1»,
       переключатель в положении «Во всём магазине»

AC-005-4 Переключатель
  WHEN страница «Ноутбуки», запрос «чехол», выбран «Во всём магазине»
  THEN подсказки по всему магазину

AC-005-5 Раскладка раньше расширения
  WHEN страница «Ноутбуки», запрос «yjen»
  THEN заголовок «Показаны результаты для „ноут“», только товары из «Ноутбуков»

AC-005-6 Вне раздела
  WHEN главная страница, запрос «чехол»
  THEN переключателя нет, поиск по всему магазину

## Backend-половина
AC-005-B1 Поддерево
  WHEN запрос с categoryId раздела «Ноутбуки»
  THEN в выдаче только товары из «Ноутбуков» и его подразделов, scope = category

AC-005-B2 Расширение
  WHEN в разделе пусто и в другой раскладке тоже пусто
  THEN выдача по всему магазину, scope = all

## Frontend-половина
AC-005-F1 Раздел в запросе
  WHEN поиск открыт на странице раздела
  THEN в запросе подсказок передан этот раздел

AC-005-F2 Заголовок по scope
  WHEN API вернул scope = all на странице раздела
  THEN показан заголовок «В разделе ничего не нашлось», переключатель «Во всём магазине»

## Границы
Вне slice: перевод раскладки (006 — сделан до), порядок по наличию (008).

## Definition of Done
- Все AC-005-* закрыты тестами с AC-ID в названиях
- Обе половины влиты, общая приёмка пройдена
- Change обеих половин удалены
