# 008 — Наличие

Тип: поведение
Основание: FR-8, FR-13, FR-14, NFR-1
Зависимости: 001, 002
Половины: backend + frontend, принимаются вместе
Результат: товары в наличии всегда выше, остальные — в конце с пометкой «Нет в наличии»;
наличие актуально на момент запроса

## Контракты
- `contracts/search.openapi.yaml` — поле inStock (не меняется)
- порт `StockReader`
- МЕНЯЕТ КОНТРАКТ: добавляет порт `SalesStats` (продажи за 30 дней). Внутренний для backend,
  openapi не затрагивается

## Fixtures для приёмки (дополняют 001)
| Товар | Склад 1 | Склад 2 | Продаж за 30 дней |
|---|---|---|---|
| Ноутбук Air | 5 | 0 | 120 |
| Ноутбук X17 | 0 | 3 | 40 |
| Ноутбук X15 | 0 | 0 | 300 |

У X15 больше всех продаж, но остатка нет — неправильный порядок провалит AC-008-1.

## Общая приёмка
AC-008-1 Наличие важнее продаж
  WHEN введено «ноутбук»
  THEN порядок: Ноутбук Air, Ноутбук X17, Ноутбук X15

AC-008-2 Пометка
  WHEN введено «ноутбук»
  THEN у «Ноутбук X15» пометка «Нет в наличии», у остальных нет

AC-008-3 Релевантность внутри наличия
  WHEN введено «ноутбук air»
  THEN «Ноутбук Air» выше «Ноутбук X17»

AC-008-4 На момент запроса
  WHEN по «Ноутбук X17» оформлен заказ на последние 3 штуки
   AND снова введено «ноутбук»
  THEN «Ноутбук X17» после «Ноутбук Air» с пометкой «Нет в наличии»

AC-008-5 По складам
  WHEN товар есть только на складе 2 («Ноутбук X17» до заказа)
  THEN он считается «в наличии»
  (добавлен после JIT-вопроса при создании Change, FR-14 уточнён)

AC-008-6 Не скрыт
  WHEN введено «x15»
  THEN «Ноутбук X15» показан с пометкой, а не «ничего не найдено»

## Backend-половина
AC-008-B1 Правило порядка
  Таблица кейсов (домен, без БД): наличие → релевантность → продажи за 30 дней;
  при равенстве всех трёх порядок стабилен

AC-008-B2 Скорость (NFR-1)
  WHEN нагрузочный тест на 50 000 товаров
  THEN p95 ≤ 150 мс с учётом наличия и продаж

## Frontend-половина
AC-008-F1 Пометка по полю
  WHEN API вернул товар с inStock: false
  THEN показана пометка «Нет в наличии»

AC-008-F2 Порядок как у сервера
  WHEN API вернул товары в порядке A, B, C
  THEN на экране порядок A, B, C

AC-008-F3 Пометка для скринридера
  WHEN скринридер озвучивает «Ноутбук X15»
  THEN звучит «Нет в наличии»

## Границы
Вне slice: регион покупателя, «под заказ», скидки, кэш (010).
Связь с 010: кэш не должен ломать AC-008-4 — решено в Dev Spec (кэш не хранит наличие).
