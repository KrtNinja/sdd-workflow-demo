# 007 — Устаревшие ответы

Тип: поведение
Основание: FR-5
Зависимости: frontend-половина 002
Половины: только frontend
Результат: на экране всегда выдача по последнему введённому запросу

## Контракты
- `contracts/search.openapi.yaml` — ответ подсказок (не меняется)

## Приёмка
AC-007-1 Поздний старый ответ
  WHEN введено «нау», затем «ноут»
   AND ответ на «нау» пришёл после ответа на «ноут»
  THEN на экране выдача по «ноут»

AC-007-2 Стёрли запрос
  WHEN введено «ноут», затем поле очищено до ответа
  THEN подсказок нет, пришедший ответ не показан

AC-007-3 Закрыли панель
  WHEN введено «ноут», панель закрыта до ответа
  THEN при повторном открытии нет выдачи по старому запросу

## Границы
Вне slice: лимит запросов (010) — это защита сервера, не клиента.

## Definition of Done
- Все AC-007-* закрыты тестами с AC-ID в названиях
- Change удалён
