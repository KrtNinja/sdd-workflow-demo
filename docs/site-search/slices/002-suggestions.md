# 002 — Подсказки

Тип: поведение
Основание: FR-3, FR-7, FR-10, FR-11, NFR-1, NFR-5
Зависимости: 001
Половины: backend + frontend, принимаются вместе
Результат: покупатель открывает поиск по иконке, вводит запрос и видит подсказки по всему магазину

## Контракты (не меняются)
- `contracts/search.openapi.yaml` — подсказки
- порт `SearchIndex`
- `tests/fixtures/search/`

## Общая приёмка (собранное приложение)
AC-002-1 Подсказки при вводе
  WHEN открыта панель поиска и введено «ноутбук»
  THEN показаны товары с «ноутбук» в названии, не больше 8 товаров и 3 категорий

AC-002-2 Короткий запрос
  WHEN введён 1 символ «н»
  THEN подсказок нет

AC-002-3 Словоформы и начало слова
  WHEN введено «ноутбука» или «ноут»
  THEN в подсказках есть «Ноутбук X15»

AC-002-4 Нормализация
  WHEN введено «Ёлка  », затем «елка»
  THEN оба запроса дают одинаковый список

AC-002-5 Переход к товару
  WHEN клик по подсказке «Ноутбук X15»
  THEN открыта страница этого товара

AC-002-6 Enter без выбора
  WHEN введено «ноут» и нажат Enter
  THEN открыта страница результатов поиска по «ноут»

AC-002-7 Поиск недоступен
  WHEN поиск недоступен и введено «ноут»
  THEN в панели «Поиск временно недоступен», остальная страница работает

## Backend-половина
AC-002-B1 Ответ по контракту
  WHEN запрос подсказок с q=ноут
  THEN 200, тело валидно по контракту, товаров ≤ 8, категорий ≤ 3

AC-002-B2 Короткий запрос
  WHEN q короче 2 символов после нормализации
  THEN 400 QUERY_TOO_SHORT

AC-002-B3 Недоступность
  WHEN поисковый индекс не отвечает
  THEN 503 SEARCH_UNAVAILABLE не позже чем через 1 с

AC-002-B4 Скорость (NFR-1)
  WHEN нагрузочный тест на каталоге 50 000 товаров
  THEN p95 ≤ 150 мс

## Frontend-половина
AC-002-F1 Пауза ввода
  WHEN быстро набрано «ноутб» (5 символов за 300 мс)
  THEN отправлен 1 запрос подсказок, а не 5

AC-002-F2 Открытие по иконке
  WHEN клик по иконке поиска в шапке
  THEN панель открыта, фокус в поле ввода

AC-002-F3 Ответ 503
  WHEN API вернул 503
  THEN показан текст из AC-002-7

## Границы
Вне slice: раздел (005), раскладка (006), хоткеи (003), стрелки и ARIA (004),
гонка ответов (007), порядок и пометка наличия (008), лимит запросов (010).
В 002 поиск всегда по всему магазину.
