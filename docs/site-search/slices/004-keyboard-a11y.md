# 004 — Клавиатура и доступность

Тип: поведение
Основание: FR-6, FR-8 (доступность пометки), NFR-2
Зависимости: frontend-половина 002
Половины: только frontend
Результат: подсказками можно пользоваться без мыши и со скринридером

## Контракты
- `contracts/search.openapi.yaml` — ответ подсказок (не меняется)

## Приёмка
AC-004-1 Выбор стрелками
  WHEN в панели подсказки по «ноут», нажато ↓ ↓
  THEN выбрана вторая подсказка

AC-004-2 Enter по выбранной
  WHEN выбрана подсказка «Ноутбук Air», нажат Enter
  THEN открыта страница «Ноутбук Air»

AC-004-3 Esc возвращает фокус
  WHEN панель открыта кликом по иконке, нажат Esc
  THEN панель закрыта, фокус на иконке поиска

AC-004-4 Роли для скринридера
  WHEN скринридер на поле поиска
  THEN поле озвучено как комбобокс, выбранная подсказка озвучивается при движении стрелками

AC-004-5 Фокус не уходит
  WHEN панель открыта, нажат Tab на последнем элементе
  THEN фокус остаётся внутри панели

## Границы
Вне slice: хоткеи (003). Сценарий «открыли по Ctrl+K → Esc → фокус вернулся» —
в общей проверке фичи, потому что требует 003 (найдено на review-slices).

- Все AC-004-* закрыты тестами с AC-ID в названиях
- Автоматическая проверка доступности без ошибок + ручная проверка скринридером
- Change удалён
