# ADR-0001: Поиск на PostgreSQL за портом SearchIndex

Статус: принято · Связано: [Dev Spec](../site-search/spec.md), FR-10–FR-13, NFR-1

## Контекст
Каталог — около 50 000 товаров. Нужны словоформы, поиск по началу слова,
фильтр по поддереву категорий, p95 ≤ 150 мс. PostgreSQL уже есть, отдельного поискового кластера нет.

## Решение
PostgreSQL full-text search (русский словарь) + pg_trgm для поиска по началу слова.
Use case работает через порт `SearchIndex`, адаптер `PgSearchIndex` — единственное место,
которое знает про tsvector.

## Альтернативы
| Вариант | Почему не сейчас |
|---|---|
| Elasticsearch / OpenSearch | Новый кластер в эксплуатации ради 50 000 документов |
| Внешний SaaS | Данные каталога уходят наружу, стоимость |

## Последствия
- Замена движка позже не трогает use case и домен — только новый адаптер.
- Если каталог вырастет на порядок или понадобятся опечатки (вне scope) — пересматриваем.
