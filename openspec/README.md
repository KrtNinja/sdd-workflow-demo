# openspec/

Здесь появляются `changes/<id>/` на время PR. Перед мержем папка Change удаляется,
`/opsx:archive` не запускаем — иначе вырастет `openspec/specs/`, второй источник правды
рядом с `docs/<feature>/spec.md`.

Образец Change: [examples/openspec-change-003-hotkeys](../examples/openspec-change-003-hotkeys/README.md).
