# Пример OpenSpec Change для slice 003

> В рабочем репозитории эта папка живёт в `openspec/changes/search-hotkeys/`
> только пока идёт PR, и **удаляется перед мержем**. Здесь она сохранена как учебный образец «строительных лесов».

Как создаётся:

```text
/opsx:propose search-hotkeys по docs/site-search/slices/003-hotkeys.md
```

Агент читает slice, Dev Spec и **текущий код**. Что он нашёл в коде:

- `shared/hotkeys/useGlobalShortcut` уже есть и используется корзиной (Esc). Он сравнивает символ,
  а не физическую клавишу — нужно расширить, а не писать второй обработчик.
- Редактор отзыва — contenteditable, проверки только input/textarea для AC-003-4 мало.
- Корзина — модальный диалог. Что делать с Ctrl+K поверх неё, в Dev Spec не было.

Третий пункт — продуктовый вопрос. Агент **остановился и спросил человека**.
Решение попало в FR-1, затем в slice как AC-003-7, и только потом Change стал готов.

Файлы: [proposal.md](proposal.md) · [tasks.md](tasks.md) · [specs/site-search/spec.md](specs/site-search/spec.md)
